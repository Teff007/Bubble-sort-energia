## Como compilar e executar

Pré-requisito: compilador GCC instalado.

Na pasta do projeto, compile todos os arquivos:

```bash
gcc main.c dados.c bubble.c interface.c -o energia
```

Execute:

- Linux / macOS:
  ```bash
  ./energia
  ```
- Windows (Prompt de Comando ou PowerShell):
  ```bash
  energia.exe
  ```

Também é possível rodar no OnlineGDB, criando os arquivos `.c` e `.h` do projeto no mesmo ambiente.
